# セル対応マッパー

Excelのフォーマットを変更したときに、旧フォーマットのデータを新フォーマットへ書き換えるためのツールです。新フォーマットのファイルは、対応づけたセル以外はそのまま（マクロ・画像・グラフも含めて）保たれます。
旧・新のシートを左右に並べ、セルどうしをクリックで対応づけて、その対応表を使って変換します。

ブラウザだけで動き、読み込んだExcelファイルが外部に送信されることはありません。

## 使い方

1. 左に旧フォーマット、右に新フォーマットの `.xlsx` / `.xlsm` を読み込みます（ドラッグ＆ドロップも可）。
2. 旧のセル → 新のセルの順にクリックすると対応づけられます。ドラッグや Shift+クリックで範囲も選べます。 範囲を選んだあとは、反対側で左上の 1 セルをクリックするだけで同じ大きさの範囲が選ばれます。
3. 新側のセルだけを選ぶと、固定値（例：`第2版`）を入れる設定ができます。「数値として入れる」にチェックを入れない限り文字列として入るので、`0123` のような先頭ゼロ付きの番号も安全です。
4. 明細行のように行数が変わる範囲は、対応一覧の「繰り返し」を押します。旧側が空行になるまで同じ範囲を下へ繰り返して転記します。
5. 「プレビュー」で、変換結果を右側に表示して確認できます（ファイルは保存されません）。
6. 「対応表を保存」で JSON を保存し、「対応表を開く」で再開できます。
7. 「変換する」で、新フォーマットのファイルに値を書き込んだファイルを作ります（`.xlsm` なら `.xlsm` のまま、マクロも残ります）。複数ファイルの一括変換もできます。

キーボードだけでも操作できます。シートにフォーカスして矢印キーで移動、Shift+矢印で範囲、Enter で選択です。

操作を試すだけなら、画面上部の「サンプルで試す」を押してください。

## 動かし方

### ローカルで使う

リポジトリをダウンロードし、`index.html` をブラウザで開くだけで動きます。
`vendor/` フォルダも一緒に置いてください。

### GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開きます。
2. **Source** で `Deploy from a branch` を選び、ブランチ `main`、フォルダ `/ (root)` を指定して保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

## 対応表（JSON）の形式

```json
{
  "tool": "cell-mapper",
  "version": 2,
  "mappings": [
    { "type": "copy",  "from": { "sheet": "申込書", "range": "B3" }, "to": { "sheet": "申込フォーム", "range": "C5" } },
    { "type": "copy",  "from": { "sheet": "申込書", "range": "A10:C10" }, "to": { "sheet": "申込フォーム", "range": "B11:F11" }, "repeat": true },
    { "type": "fixed", "value": "第2版", "asNumber": false, "to": { "sheet": "申込フォーム", "range": "G2" } }
  ]
}
```

| 項目 | 内容 |
| --- | --- |
| `type` | `copy`：旧セルの値をコピー／`fixed`：決まった値を入れる |
| `from` / `to` | シート名とセル番地。`A10:A12` のような範囲も可（旧と新で同じ大きさ） |
| `repeat` | `copy` で `true` にすると、旧側が空行になるまで同じ範囲を下へ繰り返して転記します（明細行向け） |
| `value` | `fixed` のときに入れる値（文字列） |
| `asNumber` | `fixed` で `true` にすると数値として書き込みます。省略時は、先頭ゼロのない数字だけの値のときに数値扱いになります |
| `sampleValue` | 保存時点の旧セルの値（確認用。変換には使いません） |

サンプルは [`examples/sample_mapping.json`](examples/sample_mapping.json) にあります。

## 制限

- `.xls` には対応していません。Excel で `.xlsx` に保存し直してください。
- 変換は、新フォーマットのファイルをそのまま複写して、対応づけたセルの値だけを書き換えます。マクロ（`.xlsm`）・画像・図形・グラフ・ピボットテーブル・入力規則・条件付き書式などは手を付けないので、そのまま残ります。出力の拡張子は新フォーマットと同じ（`.xlsx` / `.xlsm`）です。
- セル以外に触るのは次の 2 点だけです。(1) 開いたときに数式を再計算するフラグ（`fullCalcOnLoad`）を立てる。(2) 数式が入っていたセルを値で上書きした場合は、計算チェーン（`xl/calcChain.xml`）を外す（Excel が開くときに作り直します）。
- 書き込み先のセルに数式があれば値で上書きします。ただし共有数式の元セル（同じ数式を下へコピーした先頭のセル）は他のセルの数式を壊すため書き込まず、注意として報告します。テンプレート側でその数式を消してください。
- 新フォーマットのファイルが ZIP64 や暗号化などで直接編集できない場合、または古いブラウザで圧縮 API が使えない場合だけ、ExcelJS で書き直します。このときはマクロ・画像などが失われることがあり、結果にその旨を表示します。
- 画面に表示するのは 300 行・52 列までです（変換はシート全体が対象）。
- 数式が入っている旧セルは、計算結果の値をコピーします。Excel 以外で作られたファイルで計算結果が保存されていない場合は空になります。
- リッチテキスト（1 セル内で部分的に色や太字を変えたもの）は、文字だけを転記します。書式は新フォーマット側のものが使われます。
- 「繰り返し」で新フォーマットの用意された行数を超えて転記した場合、超えた行には新フォーマットの罫線や書式は付きません。
- 新側の結合セルには 1 つの値しか入りません。結合セルにまたがる範囲を対応づけると警告が出ます。
- 画面上のセルの表示は、Excel の表示形式（`#,##0`、`0.0%`、`yyyy/m/d`、和暦 `ggge` など）を簡易的に再現したものです。分数・指数表示・条件付き書式は再現しません。変換される値そのものには影響しません。
